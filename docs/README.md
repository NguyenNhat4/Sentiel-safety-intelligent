# Phạm vi tài liệu `docs`

Thư mục này chứa problem statement, mô tả cấu trúc hiện tại và đích, cùng các hướng dẫn kỹ
thuật. Mỗi tài liệu phải tự cung cấp đủ ngữ cảnh để đọc độc lập.

Quy tắc tài liệu:

- Không dùng file này hoặc file con làm chỉ mục điều hướng.
- Không tạo liên kết từ một tài liệu sang tài liệu khác.
- Chỉ README ở root repository được phép lập chỉ mục và liên kết tới tài liệu.
- Khi tạo, xóa hoặc di chuyển tài liệu, cập nhật chỉ mục root và mô tả filesystem hiện tại.
- Quy tắc workflow bắt buộc dành cho agent có thể chứa liên kết để nạp đúng ngữ cảnh.
