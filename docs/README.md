# Documentation Module (`docs/`)

Thư mục này chứa toàn bộ tài liệu kiến trúc, yêu cầu sản phẩm (PRD), tài liệu cấu trúc dự án và hướng dẫn cho hệ thống **P-047**.

## Danh sách tài liệu chính

- **[PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md)**: Mô tả chi tiết cấu trúc dự án hiện tại và kiến trúc định hướng trong tương lai.
- **[PRD.md](PRD.md)**: Product Requirement Document (Yêu cầu sản phẩm & phạm vi MVP).
- **[project-problem-statement.md](project-problem-statement.md)**: Mô tả bài toán và mục tiêu giải pháp.
- **[architecture_diagram.md](architecture_diagram.md)**: Sơ đồ kiến trúc tổng thể.
- **`guide/`**: Bộ hướng dẫn triển khai, anti-patterns, devops và testing.
