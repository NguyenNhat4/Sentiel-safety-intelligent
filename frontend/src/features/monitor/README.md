# Live Monitor

Owns local video playback, the explicit **Tạo vùng** workflow, revisioned multi-zone draft/applied state, normalized four-point editing, frame sampling, Canvas overlays, and grouped review orchestration. Ordinary Canvas clicks never create zones; only saved collections are sent to inference. On violation it pauses, captures the stopped native frame, and forwards typed people/SH17 boxes as transient snapshot-annotation metadata; these do not affect the safety decision or the unchanged camera-wide PPE configuration.
